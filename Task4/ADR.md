### <a name="_qmphm5d6rvi3"></a>**Решение**
1 Единый источник ставок – Deposit Service становится поставщиком данных о ставках для всех внутренних и внешних потребителей.

2 Доступ для собственного кол-центра – система кол-центра может вызывать REST API Deposit Service для получения списка ставок. Deposit Service уже имеет HTTP API для фронтов, его можно расширить новым эндпоинтом, защищённым API-ключом или JWT.

3 Доступ для партнёрского кол-центра – поскольку внешняя система не поддерживает API, выбираем файловый обмен через SFTP. DepositService по расписанию генерирует файл со ставками в согласованном формате и выгружает его на SFTP-сервер партнёра.

4 Минимизация нагрузки на АБС – чтение ставок из АБС происходит через реплику. DepositService хранит ставки в своей БД PostgreSQL, поэтому вызовы API и генерация файла не затрагивают АБС.

5 Безопасность – API для кол-центра защищён с помощью взаимного TLS или API-ключей. SFTP-доступ обеспечивается парой ключей.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1 Создание отдельного сервиса Rate Service – выделить управление ставками в отдельный микросервис. Это правильнее с точки зрения разделения ответственности, но увеличивает сложность и время разработки MVP.

2 Прямая интеграция системы кол-центра с АБС – было бы опасно из-за перегрузки АБС и сложности доступа. Отклонено.

3 Передача файла через email – менее безопасно и автоматизируемо

**Недостатки, ограничения, риски**
1 Надёжность SFTP-выгрузки – если SFTP-сервер партнёра недоступен, файл не будет доставлен. Нужен механизм повторных попыток и алертов. Deposit Service должен логировать ошибки и, возможно, сохранять неотправленные файлы для ручной обработки.

2 Безопасность API – необходимо управлять ключами доступа, обеспечить их ротацию.

3 Производительность – генерация файла может быть ресурсоёмкой, если ставок много. Планировщик не должен блокировать обработку запросов; нужно выполнять в отдельном потоке.

4 Совместимость формата – партнёр может изменить требования к формату, потребуется доработка.
